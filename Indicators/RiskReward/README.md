# RiskReward

`RiskRewardLong.mq5` dan `RiskRewardShort.mq5` adalah indikator visual risiko dan
reward pada chart. Keduanya masuk folder terminal `MQL5/Indicators/RiskReward`.

Dari root workspace:

```bash
./tools/compile_mql5.sh Indicators/RiskReward/RiskRewardLong.mq5
./tools/compile_mql5.sh Indicators/RiskReward/RiskRewardShort.mq5
```

Lihat `../../docs/BUILD.md`. File EX5 yang ada merupakan build lama.
