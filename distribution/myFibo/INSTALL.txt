myFibo 2.18 - Windows (source)

1. Simpan myFibo.zip dan install-myFibo.cmd rilis yang sama berdampingan, lalu
   jalankan CMD. Atau ekstrak lengkap ZIP dan jalankan CMD dari hasil ekstrak.
2. Jika ZIP dan folder MQL5 sama-sama ada, ZIP diprioritaskan. CMD mengekstrak
   ZIP lalu menyalin isi folder MQL5 dengan XCOPY /E /I /Y.
3. File paket langsung ditimpa tanpa backup. Jika gagal menyalin, perbaiki error
   lalu jalankan ulang CMD. Proyek lain tidak dihapus.
4. Buka Experts\myFibo\myFibo.mq5 di MetaEditor, F7, attach kembali versi 2.18.

Tujuan default:
C:\Users\qwills\AppData\Roaming\MetaQuotes\Terminal\E3E3B02889D32F38295D39BF94B6AD4A
Lokasi lain: install-myFibo.cmd "C:\path\data-folder"

Manual: pilih dua high/low candle. Memilih pengganti mempertahankan Fibo lama;
Cancel/Esc mengembalikan hasil lama. Replacement diterapkan setelah dua titik valid.
Auto: pilih Pivot (default) atau Market Structure. TF selalu mengikuti chart,
tanpa dropdown TF terpisah. Kedua metode memakai pivot kiri/kanan default 2/2,
rentang 1..20. Market Structure memakai opposing pivot sebelum BOS ke high/low
candle BOS tertutup; CHoCH menunggu BOS berikutnya dan mempertahankan gambar lama.
Sumber anchor dan penanda edit ditampilkan, terpisah dari metode yang dipilih.
Kunci anchor default off, hanya berubah melalui checkbox.

Retry label terpisah dari data/Fibo. Error data dibedakan dari no-pair. Normal
sliding windows meneruskan checkpoint arah/protected swing; gap tanpa overlap
memerlukan Cari Swing untuk reseed. Revisi histori yang masih tercache memicu
replay. Detail batas checkpoint/cache ada di MQL5/Experts/myFibo/README.md.
Schema 6 mendukung upgrade schema 5 (2.00). Schema 1..4 dihentikan. Layout GUI_v7
baru dipakai setelah upgrade; pergantian timeframe berikutnya mempertahankan layout.

Paket berisi source, tanpa manifest.json atau EX5. Kalkulasi/model terpisah dari
MyFiboChart.mqh (gambar) dan MyFiboState.mqh (persistence). Changelog ada di folder EA.
Paket tidak lagi berisi script contoh Market Structure. Test tetap ada di workspace.
Runner lokal C++/fake API tidak membuktikan kompilasi atau rendering native MQL5.
F7, interaksi GUI/chart, server history dan CMD perlu diverifikasi di Windows.

Referensi lokal ada di reference/standard-library-guide.md. Downloader PDF/CHM
resmi: reference/download-reference.cmd; perlu internet dan tidak dijalankan
secara otomatis oleh installer.

Versi 2.11: anotasi chart berada di belakang GUI; inisialisasi variabel swing
diperjelas untuk menghindari warning last. Verifikasi tampilan dan F7 di Windows.

Versi 2.12: installer hanya ekstrak dan copy/overwrite. Tidak ada pemeriksaan
manifest, hash atau versi, dan tidak ada backup Windows.

Versi 2.13: Auto mengikuti TF chart dan analisis baru dijadwalkan lewat timer.
Label/checkpoint TF lama dibersihkan; Manual/anchor terkunci tetap dipertahankan.
Melepas kunci melanjutkan analisis pada TF chart baru.

Versi 2.14: GUI tidak lagi menampilkan TF, Chart atau nama timeframe. Analisis
tetap mengikuti timeframe chart. Sumber menunjukkan asal anchor Fibo yang digambar.

Versi 2.18: semua program contoh dikeluarkan dari paket. Salinan lama
FibonacciExample, SwingDetectorExample, dan MarketStructureExample di
MQL5/Scripts boleh dihapus manual (.mq5 dan .ex5). CMD hanya menyalin file;
tidak menghapus file lama di terminal.
