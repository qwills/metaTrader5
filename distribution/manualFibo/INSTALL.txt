manualFibo 1.19 - Windows (source)

1. Place manualFibo.zip beside install-manualFibo.cmd, or extract the entire ZIP.
2. Run install-manualFibo.cmd. It extracts and copies/overwrites MQL5 contents
   without creating backups or checking hashes/versions. It does not delete old files.
3. Default terminal Data Folder:
   C:\Users\qwills\AppData\Roaming\MetaQuotes\Terminal\E3E3B02889D32F38295D39BF94B6AD4A
   Other location: install-manualFibo.cmd "C:\path\data-folder"
4. Open Experts\manualFibo\manualFibo.mq5 in MetaEditor and press F7.
5. Attach manualFibo 1.19 to a chart. Use a separate chart if running AutoFibo too.

Package includes Experts/manualFibo, the required headers in Include/_common/Fibo, the CMD and
instructions. No EX5, Auto/market-structure libraries, examples or tests are included.
Standard Library Controls headers come from the installed MT5 terminal.

Click Pilih Swing, select two candle highs/lows, then tick desired ratios.
23.6%, 38.2%, 50%, 61.8%, 78.6% and 88.6% are available.
Defaults: 50%, 61.8%, 78.6%. No checkbox or drawn level for 0% or 100%.
Kunci anchor is unchecked by default. Double-click the object to edit anchors.
Unchecking every ratio hides the object without discarding anchors. Batal/Esc
retains the previous completed swing; Reset removes it but keeps checkbox choices.
Timeframe changes preserve completed anchors/choices and cancel pending selection.

Build checks on macOS use C++ adapters, not MetaEditor. F7, native GUI rendering,
panel drag/minimize, object edits, persistence and this CMD need Windows testing.

RISK / LOT PREVIEW
Default risk is 5 percent of current account equity. Per level applies that risk
to each checked level; All shares one budget across the selected levels.
Enter another percentage in the Risk box. Each level has an editable SL price,
initially following the swing start. Finish editing to apply. Clear an SL field
to resume following the swing start. Edited SLs remain fixed when anchors move.
Checked levels show lots and estimated loss in account currency. SL must be on
the loss side of entry; invalid stops and insufficient minimum-lot risk show a
message instead of lots. Risk/custom SL settings survive timeframe changes.
Reset clears SL overrides while retaining risk/ratio choices.

Calculations normalize prices to symbol tick size and round lots down. They do
not include commissions, swap, slippage/gaps, margin checks or existing exposure.
Risk is independent per row, so multiple orders can exceed the displayed budget.
This release sends checked levels with the Send Orders button; see below.
In Windows verify SL/risk editing, BUY LIMIT/SELL LIMIT estimates, broker data and account-
currency conversion, timeframe persistence, timer refresh and input focus.

Source 1.15 optimization: one account/symbol snapshot per refresh, no lot work
while minimized, immediate refresh on restore, and independent input recovery.
Risk supports eight decimal places; values too small to display are rejected.
Native MetaEditor F7, broker behavior and GUI rendering still need Windows tests.

Source 1.15 limit-only previews:
Entry below the current Bid/Ask spread is BUY LIMIT; entry above it is SELL LIMIT.
Entry inside the spread or equal to Bid/Ask is unavailable. Swing direction does
not select the order side. BUY STOP and SELL STOP are never selected.
Minimum pending-entry and SL distances are checked against the broker stop level.
Invalid levels clear their lot/loss estimate and show a reason. The lot tooltip
includes the limit type. No additional Order column or per-level send controls;
actual limit submission now uses one shared Send Orders button.

Source 1.15: reusable model/risk/GUI/chart/state headers are now under Include/_common/Fibo,
shared with AutoFibo. Copy the ENTIRE Include/_common/Fibo folder with Experts/manualFibo.
The old ManualFibo*.mqh sibling files are no longer referenced. Manual selection,

Old MQL5/Include/Fibo files are no longer used by this release; the installer

SOURCE 1.16: LIMIT ORDER EXECUTION
Copy ALL Experts/manualFibo headers, including ManualFiboDialog.mqh and
ManualFiboOrders.mqh, plus the complete Include/_common/Fibo folder. Press F7.
OrderMagic defaults to 11600101 (nonzero); reserve it for manualFibo.
Send Orders immediately sends every NEW checked level as BUY LIMIT or SELL LIMIT.
TP: swing end is checked by default; uncheck it to send without TP. Invalid TP,
SL, risk, margin or broker checks block the batch before sending. Prices and
account state may still change mid-batch. Risk remains PER LEVEL (5% default).
Total estimated loss sums all checked rows, not existing exposure.
Repeated clicks skip accepted setups/levels. Definite failures alone can retry.
Timeouts/unknown results are blocked; inspect Experts/Trade/History first.
Delete Orders cancels all manualFibo pending limits for the current symbol and
OrderMagic, including previous setups. It does not close positions or touch stop
orders/other EAs. Already sent/deleted levels remain blocked for that anchor setup.
Moving Fibonacci or removing the EA does not change submitted orders. TP choice
survives timeframe changes. Details and duplicate-protection limits are in README.
Verify sending/deleting, broker rejection/partial failure and timeframe behavior
on a demo account in Windows; adapter tests do not contact any broker.

SOURCE 1.17: RISK MODES AND RECONCILIATION
Copy the new ManualFiboReconcile.mqh with the other EA headers. Per level remains
the default. All divides one equity-risk budget equally across selected levels;
lot rounding can leave unused budget. The compact Risk field has the numeric
money amount beside it, plus an All / Per level selector. Risk mode survives TF
changes. Prior successful/uncertain submissions reserve risk for the same setup;
retrying or unchecking them never allocates the full budget again. Legacy setup
records without saved risk block All continuation rather than guess.
OnTradeTransaction and a bounded timer resolve unknown results using request IDs,
tickets and owned active/history evidence. Proven rejection permits user retry;
absence alone does not. No automatic sends or extra per-level status display.
Polling stops when there are no unknowns and backs off while awaiting evidence.
F7 and demo checks for risk totals, partial retries and reconnects remain required.

SOURCE 1.18: STARTUP FIX
Copy the updated manualFibo.mq5 AND ManualFiboDialog.mqh, then press F7 and attach

Experts now logs the initialization stage if attachment still fails.

SOURCE 1.19: MUTEX FIX
Copy manualFibo.mq5 and ManualFiboOrders.mqh, then F7. Existing free locks are
reused; creation/acquisition failures are distinguished from a busy lock.
Experts logs the lock key/value/error. Do not delete submission/risk records.
If no operation is active but a session lock remains busy, restart the terminal;
if still blocked, use the Experts diagnostic line to identify the problem.
